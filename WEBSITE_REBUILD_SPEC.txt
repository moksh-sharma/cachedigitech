Global Application Behavior
---------------------------
File: frontend/src/App.jsx

- Uses route-level lazy loading for almost all pages.
- Suspense fallback: centered "Loading..." pulse UI.
- Includes persistent shell components:
  - Navbar (top, fixed)
  - Footer (bottom)
  - CookieBanner (global cookie consent)
- Loader removal logic:
  - Targets DOM element #app-loader with optional image #app-loader-img.
  - Intended GIF loop duration: 5000ms.
  - Safety fallback max wait: 1500ms.
  - On completion, removes loader from DOM and sets loaderDone=true in AppLoaderContext.
- Route change behavior:
  - Scroll to top using Lenis scrollTo if available.
  - Lenis resize is called shortly after route change for recalculation.
  - Fallback: native smooth window.scrollTo.

Navigation Architecture
-----------------------
Primary nav files:
- frontend/src/components/HomeComponent/Navbar.jsx
- frontend/src/components/HomeComponent/navLinks.ts

Navbar behavior:
- Desktop:
  - Floating translucent rounded navbar with blur.
  - Mega menu with multi-column nested items.
  - Hover-to-open and delayed close behavior.
  - "Careers" and "Contact" are direct-link sections (not mega menus).
- Mobile:
  - Full-width slide-in sidebar.
  - Nested submenu panel with back navigation.
  - Body scroll lock when menu open.
- Scroll behavior:
  - Navbar turns "scrolled" after Y > 60.
  - Hides on scroll down and reappears on scroll up.
  - Top threshold to keep it visible near top.
- Route-aware styling:
  - Supports dark-hero pages and light-text navbar mode at top.

Footer behavior:
- Separate desktop and mobile layouts.
- Mobile: accordion sections + social links + contact CTA.
- Desktop: multi-column navigation, social row, legal modal triggers.
- Legal modal content lazy-loads:
  - PrivacyPolicyPage
  - TermsOfUsePage

Global Consent and Analytics
----------------------------
Cookie Consent:
- Context: frontend/src/context/CookieConsentContext.jsx
- Banner: frontend/src/components/CookieBanner.jsx + CookieBanner.css
- Stores consent states: null / accepted / rejected.
- On accepted:
  - Injects Google Analytics script from googletagmanager
  - Initializes gtag with measurement ID: G-S517TXV48S
- Banner supports animated entry/exit.

- Component: frontend/src/components/FloatingChatbot.jsx
